# BridgeGuards4EducatedSudan
A Geospatial AI framework to ensure education continuity for IDP children in Sudan using ACLED and IOM open data.

## Repository Structure

- `data/`
    - `raw/`: Original, immutable data source files (ACLED, IOM, OSM, etc.).
    - `processed/`: Datasets generated by the processing scripts (e.g., `data.csv`, `sudan_map_data.json`).
    - `external/`: Third-party reference data (e.g., admin boundaries).
- `src/`: Python scripts for data processing and analysis.
- `web/`: Frontend map application (`index.html`).
- `docs/`: Additional project documentation and data dictionaries.

## Getting Started

1. **Process Data**: Run the scripts in `src/` to generate the latest processed datasets.
2. **View Map**: Open `web/index.html` in a web browser to view the interactive map.
